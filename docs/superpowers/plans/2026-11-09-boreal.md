# BOREAL Implementation Plan

**Goal:** Add the approved Earth polar station as fourth diorama.
**Architecture:** Independent polar scene controller and focused terrain, materials, buildings, ship, aircraft, ground actors, weather/trails modules. Shared modelAssembly and fixed practical-light pool, no city/Mars behavior changes.
**Tech Stack:** Existing React/TypeScript/Babylon.js/Vite PWA.
**Spec:** docs/superpowers/specs/2026-11-09-boreal-design.md
**Execution:** Inline in current checkout, approval already given. No agents, publishing or automatic commit. Model sourcing was subsequently authorized; use matching Babylon glTF loaders and a local Meshopt decoder.

- [x] `polar/state.ts`, `terrainMath.ts`, `tests/polar.test.mjs`: persisted four settings, continuous approach/touchdown/deceleration/taxi/ramp timeline, flat runway/base and coastal relief. Test meaningful phase/terrain boundaries.
- [x] `polar/materials.ts`, `terrain.ts`: granular snow/ice, layered glacier, actual drifts, ice floes, dark animated water and night aurora; snow/ice material contrast.
- [x] `polar/base.ts`: elevated modules with open glazed interiors, stairs/rails, open workshop, detailed power/radio/drilling/core equipment, plowed lanes and old outpost.
