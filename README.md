# Yoru · Nox · Ares · Boreal — 3D-PWA

Die Anwendung liegt in `neon-district/`.

```sh
cd neon-district
npm install
npm run dev
```

Für eine installierbare Produktionsvorschau:

```sh
cd neon-district
npm run build
npm run preview -- --port 4187
```

Anschließend `http://localhost:4187` öffnen. Die Installationsoption hängt vom Browser ab. Die Offline-Funktion steht nach dem ersten vollständigen Laden bereit.

Weitere Hinweise, Steuerung und Asset-Herkunft: [Projekt-README](neon-district/README.md).

Abnahme und bekannte Grenzen: [Prüfbericht](docs/verification.md).
